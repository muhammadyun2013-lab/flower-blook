FLOWER BLOOK — ДЕНЬ УЧИТЕЛЯ

1) Распакуйте ZIP.
2) Установите Node.js (https://nodejs.org/), если он не установлен.
3) Дважды нажмите ЗАПУСТИТЬ_ИГРУ.bat. Появится страница с ДВУМЯ ссылками:
   УЧИТЕЛЬ — создание игры и получение кода.
   УЧЕНИК — ввод кода от учителя и имени.
4) На компьютере учителя создайте комнату, запишите код.
5) Для ученика на том же компьютере откройте вторую ссылку в другом окне браузера.
6) Для подключения учеников с других устройств используйте адрес вида
   http://IP-КОМПЬЮТЕРА-УЧИТЕЛЯ:3000/?role=student
   (одна сеть Wi-Fi; доступ через брандмауэр должен быть разрешён).
   localhost на другом устройстве не работает!
7) Для учеников через Интернет разместите сервер на общедоступном хостинге.

ВОПРОСЫ: questions.csv редактируется в Excel. Учитель нажимает «Загрузить CSV», затем «Сохранить».
ФОТО: учитель загружает фото учителей и сохраняет настройки; смена каждые 1000 общих цветов.
НАГРАДЫ: +10, +20, +50, x2, -10%, -25%.
ВАЖНО: сервер должен оставаться запущенным, пока ученики играют.

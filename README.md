# Flower Blook — публичная викторина ко Дню учителя

## Как опубликовать (GitHub + Render)

1. Распакуйте ZIP **на компьютере**.
2. Откройте GitHub-репозиторий `flower-blook` → Add file → Upload files.
3. Загрузите **содержимое** этой папки. На главной странице репозитория должны лежать `package.json`, `server.js`, `questions.csv`, `render.yaml`, папка `public`.
4. Нажмите Commit changes.
5. В Render → flower-blook → Settings установите Build Command: `npm install`, Start Command: `npm start`. Root Directory **пустой** (если файлы загружены в корень).
6. В Render → Deploys → Manual Deploy → Deploy latest commit. Дождитесь статуса Live.

### Игра
- Учитель: `/` → «Учитель» → создать комнату и получить 6-значный код.
- Ученик: `/` → «Ученик» → ввести код и имя, выбрать персонажа.
- Учитель настраивает вопросы, загружая файл CSV через раскрывающийся блок «Настроить вопросы CSV и фотографии учителей», и нажимает «Сохранить».
- Для фотографий учителей загрузите изображения в той же панели, потом нажмите «Сохранить». Используйте фото с разрешения учителей, так как игра публичная.
- После правильного ответа ученик выбирает 1 из 3 подарков; награда выпадает случайно (+10/+20/+50/×2/−10%/−25%). Фото сменяется каждые 1000 цветов.

### CSV
`questions.csv`: колонки `question,answer1,answer2,answer3,answer4,correct`, где correct — число 1–4. В наборе 30 вопросов по sin, cos, tg, ctg.

### Локальная проверка
Установите Node.js; откройте командную строку в **распакованной** папке и выполните `npm start` (нет сторонних зависимостей). Перейдите на `http://localhost:3000`.

### Ограничения
Render Free может выключать сервер из-за простоя. Состояние игроков и цветы хранятся в оперативной памяти, поэтому при перезапуске Render игра обнулится. Новую комнату создавайте перед мероприятием. ZIP сам по себе не является работающей интернет-ссылкой.
